# The Simplest Calorie Tracker Website

Marketing website for [The Simplest Calorie Tracker](https://apps.apple.com/us/app/the-simplest-calorie-tracker/id6761067469), built with Next.js and hosted on Vercel.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production deployment

The Vercel project is connected to this GitHub repository. Every push to `main` automatically creates a production deployment. Pull requests and non-production branches create preview deployments.

Before pushing, run:

```bash
npm run build
```

Production: [thesimplestcalorietracker.com](https://thesimplestcalorietracker.com)
